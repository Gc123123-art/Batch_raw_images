# BOLI AI 批量图片生成工具 — 产品需求文档 (PRD)

> ⚠️ **本文档已过时**：命令行版（CLI）已迁移至独立项目，
> 本平台现为 Web 版（用户注册/登录、Web 界面提交任务、按图扣费）。
> 以下内容仅作为 CLI 时期的历史需求参考。

## 1. 项目背景

基于 DONGLI AI 开放平台 API，开发一个批量图片生成工具，支持**文生图**和**图生图**两种模式，帮助用户高效批量生成图片，避免手动逐条调用 API 的重复劳动。

## 2. 产品目标

- 提供命令行脚本，支持用户通过编辑 CSV 文件配置批量任务
- 支持文生图（text-to-image）和图生图（image-to-image editing）两种模式混合处理
- 支持并发请求，提升批量处理速度
- 自动保存生成结果，记录执行日志

## 3. 用户角色

- **普通用户**：无编程背景，会编辑 Excel/CSV 文件，能运行 Python 脚本
- **进阶用户**：有编程背景，可能需要二次开发或集成到自己的流程

## 4. 功能需求

### F1. 批量文生图
| 项目 | 描述 |
|------|------|
| 输入 | 多个 prompts（描述词）从 CSV 读取 |
| 处理 | 调用 `POST /v1/images/generations` |
| 参数支持 | `prompt`（必填）、`size`、`n`、`response_format` |
| 输出 | 图片文件保存到本地，记录存储到 results.csv |

### F2. 批量图生图
| 项目 | 描述 |
|------|------|
| 输入 | 参考图路径 + prompt 从 CSV 读取 |
| 处理 | 调用 `POST /v1/images/edits`（multipart/form-data） |
| 参数支持 | `reference_image`（必填）、`prompt`（必填）、`size`、`n` |
| 输出 | 图片文件保存到本地，记录存储到 results.csv |

### F3. 混合模式
- 同一份任务 CSV 中，部分行是文生图（无参考图），部分行是图生图（有参考图）
- 脚本自动识别并调用对应接口

### F4. 并发处理
- 支持可配置的并发数（默认 3 个同时请求）
- 使用多线程加速，同时不超出 API 频率限制

### F5. 任务输入（CSV 格式）
- 支持 UTF-8 编码，首行为字段名
- 字段：`prompt`, `reference_image`, `size`, `n`, `response_format`
- 支持 `#` 开头的注释行（跳过处理）

### F6. 输出管理
- 图片自动命名：prompt前60字符 + 序号 + 时间戳
- `results.csv` 记录每条任务的执行状态、生成文件路径、错误信息
- 图片与记录分别存放在 `output/images/` 和 `output/results.csv`

### F7. 错误处理与容错
| 错误码 | 处理方式 |
|--------|---------|
| 400 | 记录为"参数错误或内容违规"，继续下一个任务 |
| 401 | 终止运行，提示用户检查 API Key |
| 402 | 记录为"余额不足"，继续下一个任务 |
| 500 | 记录为"服务端错误"，继续下一个任务 |
| 网络超时 | 等待超时后记录失败，继续下一个任务 |

- 单任务失败不影响其他任务的执行
- 最终汇总成功/失败统计

### F8. 断点续传（可选增强）
- 记录已处理的任务，下次运行时自动跳过已成功的任务
- 仅重试失败的任务

### F9. 配置管理
- 供应商 API Key、默认参数、并发数通过数据库 `api_providers` 表管理（管理员接口维护）
- 平台级密钥（管理员 Key / JWT）通过环境变量注入，避免敏感信息硬编码在代码中

## 5. 非功能需求

| 项目 | 要求 |
|------|------|
| 运行环境 | Windows 10/11，Python 3.8+ |
| 依赖包 | 仅 `requests`、`python-dotenv`，最小化依赖 |
| 易用性 | 提供清晰的 tasks.csv 模板和注释说明 |
| 安全性 | 供应商 API Key 存数据库（管理员接口维护），平台密钥走环境变量，不写入代码 |
