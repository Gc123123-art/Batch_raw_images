# 多参考图图生图 — 操作指南

> 适用范围：Batch_raw_images 网页版
> 功能：一次上传 2~6 张参考图，让 AI 同时参考"模板/边框"和"商品素材"，生成融合后的图片。

---

## 1. 功能简介

网页版最多支持 **6 张参考图**。例如：

- **图1**：边框/版式模板（电商主图风格、标题位置、装饰元素）
- **图2**：商品素材（要放入模板的商品图）

AI 会同时理解两张图：保留图1 的框架与排版，把主体替换为图2 的商品内容。

---

## 2. 基本原理（为什么之前只识别一张？）

| 项目 | 说明 |
|------|------|
| 旧实现的问题 | 后端用 `image_2`、`image_3` 字段上传多张图，但 OpenAI 兼容的 `/v1/images/edits` 接口只认一个 `image` 字段，多余的图被服务端直接丢弃 |
| 现在的解决方案 | 多张参考图先在本地**合成为一张大图**（带"图1/图2/图3"红色角标），再以单 `image` 字段提交，保证所有参考图都进入模型视野 |

**合成布局规则：**

- **2 张**：左右并排（图1 在左，图2 在右）
- **3~4 张**：2×2 网格（3 张时最后一行居中）
- **5~6 张**：3×2 网格（5 张时最后一行居中）
- 每张子图统一为 512×512，白底拼合，按从左到右、从上到下的顺序排列（即"图1=左上 / 图2=右上 / 图3=左中…"）

---

## 3. 网页版操作步骤

### 3.1 打开生成页面

1. 浏览器访问 `http://localhost:8001`（前端）或登录后进入"生成图片"页面
2. 确保后端 `api_server.py` 已启动（`http://localhost:8000`）

### 3.2 上传参考图（支持 3 种方式）

在"参考图片"区域点击 **＋** 按钮：

| 方式 | 操作 | 说明 |
|------|------|------|
| 单张/多张选择 | 点击＋，在弹出的文件选择器中**多选**（Ctrl/Shift）多张图片 | 一次可加多张 |
| 粘贴图片 | 直接 Ctrl+V 粘贴剪贴板中的图片 | 自动转存上传 |
| ZIP 批量 | 点击＋选择 `.zip` 压缩包 | 自动解压，取前 6 张图片作为参考图 |

**上传后**：缩略图区会按顺序显示 1~6 张参考图，可点"×"删除重新调整。

> 注意：参考图顺序 = 合成顺序 = 图1/图2/图3/...，请把"模板/边框"放第一张。

### 3.3 填写提示词（关键）

多参考图模式下，**请明确说明每张图的作用**，例如：

```
图1 是电商主图边框模板，图2 是商品素材。
请保留图1 的边框、标题排版和装饰元素，
将主体商品替换为图2 的商品风格。
```

再举一个例子（两张图都是商品场景）：

```
图1 是左图的产品展示，图2 是右图的背景布景。
请把图2 的背景融合到图1 的产品上，生成一张统一的电商主图。
```

### 3.4 选择参数并生成

1. 选择画幅（1:1 / 3:4 / 9:16 / 16:9）
2. 填写生成数量
3. 点击"生成"按钮
4. 等待任务完成，预览/下载结果

---

## 4. 提示词写法建议

| 场景 | 推荐写法 |
|------|----------|
| 模板 + 商品 | "图1 是模板边框，图2 是商品，保持图1 的版式，主体换成图2 的商品" |
| 参考风格 + 换主体 | "图1 是构图/光影参考，图2 是要生成的主体素材，融合两者" |
| 多素材合成 | "图1、图2 都是素材，把它们合成到一个画面上，布局自行设计" |

**避坑提示：**

- ❌ 不要写"图二的商品图生成…"，角标编号是"图1/图2"（中文数字不是"图二"），建议用"图1/图2"避免歧义
- ❌ 不要只描述"参考图"而不指明是哪一张
- ✅ 一次任务里最多 6 张，超过的会被丢弃（前端已限制最多 6 张）

## 6. 常见问题（FAQ）

| 问题 | 解答 |
|------|------|
| 生成的图还是只用了第一张参考图？ | 确认后端已重启（`api_server.py` 不热重载，改代码后需重启）；确认上传顺序，模板/边框放第一张 |
| 参考图合成后糊了？ | 合成时统一压缩为 512×512，细节会有损失；建议上传原始清晰图片，提示词里说明"保持图1 版式" |
| 最多能传几张？ | 网页版最多 6 张；超过会被丢弃 |
| 想调整参考图顺序？ | 删除缩略图后重新上传即可，第一张即"图1" |
| 生成的图片和参考图长得不一样？ | 多参考图融合属于"风格/元素参考"，AI 不会 1:1 复制；提示词越具体，效果越可控 |
