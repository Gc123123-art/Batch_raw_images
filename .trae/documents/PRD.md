# BOLI AI 批量图片生成平台 — 前端 PRD

## 1. 产品定位

面向 B 端客户的批量图片生成 SaaS 平台 Web 界面，与 Python FastAPI 后端解耦，可独立部署。

## 2. 用户目标

- 客户登录后用 prompt + 可选参考图批量生成 AI 图片
- 上传一张参考图 + prompt 即可批量处理多张
- 实时查看生成进度，按张数扣费
- 查看历史任务和已生成图片

## 3. 目标用户

- 中小电商 / 设计工作室 / 内容创作者
- 需要批量产出图片素材、但不想自己接 API

## 4. 信息架构

```
登录 / 注册
   ↓
仪表盘 (Dashboard)
   ├── 余额显示
   ├── 快捷创建任务
   │   ├── 文生图
   │   ├── 图生图 (上传单张参考图)
   │   └── 批量图生图 (上传 ZIP 包含多张参考图)
   └── 任务列表
        └── 任务详情
             ├── 进度条
             ├── 生成结果预览
             └── 单图下载
```

## 5. 核心页面

### P1. 登录 / 注册页
- 居中卡片布局，账号 + 密码输入
- 注册时显示 "新用户注册送 10 次体验"
- 错误提示醒目

### P2. 仪表盘（首页）
- 顶部导航栏：Logo / 余额 / 账号
- 主体三栏：左侧任务历史，右侧创建任务
- 创建任务区支持三种模式切换

### P3. 任务详情页
- 顶部显示任务元信息（创建时间、状态、总张数）
- 进度条 + 完成数
- 网格展示每张生成结果
- 失败项有错误信息提示
- 单张图片可点击放大预览

## 6. 视觉风格

| 维度 | 选择 | 理由 |
|------|------|------|
| 风格 | 现代专业感，参考 Linear / Vercel | 面向 B 端客户，不浮夸 |
| 主色 | 冷色调蓝紫 (近黑背景 + 蓝色高亮) | AI 行业普遍风格，专业感 |
| 字体 | 标题用 Noto Serif SC + 正文用 Geist | 中英兼顾，有专业气质 |
| 动效 | 入场渐显 + 进度条缓动 | 微动效不喧宾夺主 |
| 布局 | 12 栏响应式 + 大量留白 | 现代极简 |

## 7. 交互流程

```
新用户 → 注册（自动登录）→ 仪表盘
老用户 → 登录 → 仪表盘
    ↓
选择模式 (文生图 / 图生图 / 批量图生图)
    ↓
填写 prompt + 选择参考图 (如有)
    ↓
点击「生成」→ 提示扣费确认 → 后台异步执行
    ↓
页面跳转到任务详情 → 轮询进度 → 完成后展示结果
```
